Architecture
A Raspberry Pi voting kiosk with dual thermal printers, smart-glass print windows, and motorised paper handling.

The application is a single-file Tkinter kiosk (main.py) running fullscreen on a 480×800 portrait display. It drives two thermal printers, two DC/Servo motors, two PDLC smart-glass panels, and a set of status LEDs — all over the Raspberry Pi GPIO header.

Hardware Stack

  • ControllerRaspberry Pi (BCM GPIO)
  • Display480 × 800 portrait touch
  • Printers2 × 58 mm thermal, USB lp0/lp1
  • MotorsDC (default) / Servo / Both
  • Print Windows2 × PDLC smart glass
  • LEDs2 window LEDs + Green/Red status
  • StorageSQLite (unique 12-digit barcodes)

Voting Flow — Screen-by-Screen

  1. Home — open_vote_window(). Hardware reset to defaults (glass OFF, LEDs OFF, green ON).
  2. Constituency — show_constituency_screen(). “Is your constituency XYZ?” Yes/No, 100 s timer.
  3. Symbol Grid — grid_screen(). Scrollable 2-col grid of party symbols loaded from assets/images/.
  4. Confirm Symbol — open_image_screen(). Enlarged preview, Yes/No.
  5. Print Stage — accept_image() → select_printer() → print_image(). Glass turns transparent, window LED lights, motor rolls paper out, printer prints rotated symbol image.
  6. Confirm Print — confirm_print_screen(). Yes → print VOTED + EAN-13 barcode. No → print REJECTED.
  7. Thanks / Terminated — voting_thanks_screen() or voting_terminated_screen(). Auto-returns Home.
  8. Settings (passcode) — setting_screen(). Editor for every config.ini section, persisted via save_config().

The Smart-Glass Choreography

This is the signature behaviour of the kiosk — what happens between “Yes, this is my symbol” and the ballot being visible:

  1. Random printer chosen (or fixed via PRINTER_CONFIG.which_printer).
  2. Red LED ON, Green LED OFF.
  3. Smart glass of that window switches to transparent.
  4. Window LED below the glass turns ON, illuminating the ballot area.
  5. DC motor for that side starts rolling.
  6. Thermal head prints the rotated symbol image.
  7. After motor_delay_time_*_motor seconds the motor stops.
  8. On confirm: a second pass prints VOTED + barcode (or REJECTED).
  9. Return to Home → glass and LEDs OFF.

Deployment

Runs as a systemd service (install/vpm.service) auto-starting on boot. Logs to syslog and restarts on crash. The current user must be in the lp group for printer USB access.
